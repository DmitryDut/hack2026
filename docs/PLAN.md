# План реализации (итерации, шаги, TODO)

**Единственный источник правды по шагам.** Закончил шаг → поставь `[x]` в том же коммите (`PLAN: P0.3 …`). Нашёл долг или отложил решение → сразу строка в разделе **TODO** в том же коммите. Прогресс: `make progress`, открытые TODO: `make todo`.
Требования — `requirements.md`, техника — `SPEC.md`, макеты — `ui/`, сценарии — `scenarios.md`. Задачи верхнего уровня — `tasks/BOARD.md`.
Формат шага: `- [ ] ID текст (≈мин)`; формат TODO — таблица ниже, последняя колонка `[ ]` / `[x]`.
