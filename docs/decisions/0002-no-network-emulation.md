# ADR 0002: Сеть оператора не эмулируется

**Решение:** «подключение услуги абоненту» = запись в БД, смена статуса `SubscriberService` и `AuditEvent`.
**Почему:** блок «управление услугами на сети» вне нашего скоупа; для демо достаточно видимого результата.
**Последствия:** если понадобится показать «сетевой» эффект — отдельный ADR и мок-сервис.
