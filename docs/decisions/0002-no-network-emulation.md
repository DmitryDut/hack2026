# ADR 0002: Внешние системы и сеть — встроенные моки с журналом

**Решение:** PX, Resource Catalog и GSMA QoD APIgw имитируются модулями внутри приложения (`app/mocks`) с теми же путями и форматами, что в задании. Каждый «исходящий» вызов сохраняется в `NetworkRequest` и виден в UI. Сеть (SCEF/NEF/PCRF/радио) не эмулируется.
**Почему:** по заданию «песочница — чистая эмуляция» [T 2d], реальные системы недоступны; отдельные сервисы утяжелят запуск на одной машине.
**Последствия:** замена мока на реальный вызов — правка одного модуля. Если появятся спецификации PX/APIgw, меняем только мок и маппинг в `config/px_payload.yaml`.
