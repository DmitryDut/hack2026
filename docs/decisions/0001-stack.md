# ADR 0001: Стек

**Решение:** Python/FastAPI + SQLModel/SQLite + Jinja2/HTMX/Pico.css (CDN), uv.
**Почему:** POC, финал запускается на одной машине; один язык, один процесс, без Docker, без сборки
фронтенда, Swagger из коробки. Агентам проще работать с одним стеком.
**Последствия:** без миграций (`create_all` + `make reset`); смена стека — только новым ADR.
