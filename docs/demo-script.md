# Сценарий демо (он же приёмочный тест — `tests/test_demo_flow.py`)

1. **Партнёр**: регистрация → мастер онбординга (данные компании, документы-заглушки, тех. контакт) → «Отправить на проверку».
2. **Оператор** (`/operator`): список заявок → карточка → «Одобрить» → партнёру выдан API-ключ.
3. **Партнёр**: выбирает схему подключения, задаёт параметры → оператор подтверждает → подключение `active`.
4. **Партнёр**: выбирает продукт и абонента по MSISDN (UI или `POST /api/v1/subscribers/{msisdn}/services`
   с `X-API-Key`) → услуга `active`.
5. **Карточка абонента** (`/subscribers/{msisdn}`): подключённые услуги, QoS-профиль, таймлайн событий (AuditEvent).

Запуск подготовленного демо: `make reset && make dev`.
