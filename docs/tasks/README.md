# Протокол работы с задачами

Репозиторий: https://github.com/DmitryDut/hack2026 — общая точка синхронизации агентов.

1. `git pull`. Возьми задачу `todo` из [BOARD.md](BOARD.md): поставь `in_progress`, своё имя
   (`claude` / `codex` / `cursor`), ветку `t-XXX-short-name`. Закоммить и запушь это изменение BOARD.md
   сразу (метка «занято»), чтобы другой агент не взял ту же задачу.
2. Работай в отдельном worktree: `git worktree add ../hack-t-XXX -b t-XXX-short-name`.
3. Делай только то, что в карточке `T-XXX-*.md`. Вне скоупа — не трогай, заводи новую карточку.
4. Готово: `make check` → допиши «Журнал» в карточке → коммит `T-XXX: описание` →
   `git pull --rebase origin main` → merge в `main` → `git push` → статус `done` в BOARD.md.
5. Если не закончил — статус остаётся `in_progress`, в «Журнал» запиши, что сделано и что осталось.

## Шаблон карточки
```
# T-XXX: название
Цель / Контекст и файлы / Критерии приёмки / Вне скоупа / Зависит от / Журнал
```
