# T-014: Личный кабинет партнёра

**Цель:** CAB-1…CAB-4, SBX-11, PROC-2, PROC-3 — основной экран партнёра. Макеты: `docs/ui/02-cabinet.md`, `03-subscriber.md`; сценарии S-02…S-08 в `docs/scenarios.md`.
**Файлы:** `app/web/cabinet.py`, `app/services/priority.py`, `app/templates/cabinet/*`, `config/process.yaml`, тесты `test_priority.py`, часть `test_demo_flow.py`.
**Критерии приёмки:**
- `/cabinet`: баннер приоритета, таблица услуг (тариф, срок, стоимость, статус), итоги «запущено / в черновиках / всего».
- Карточка услуги: вкладки из `process.yaml` (данные, тариф и стоимость, тестирование, запуск), недоступные вкладки серые с причиной (`gates`).
- «Тариф и стоимость»: таблица тарифов со стоимостью по каждому, выбор срока, разбор расчёта (`SPEC.md` §3, D15), подтверждение цены.
- `/cabinet/offer`: варианты, сравнение, JSON для PX, отправка в витрину.
- Признак `⚡ Трафик приоритизирован` — через `priority_view` в кабинете и витрине; «⏱ Срок истёк» после `expires_at`.
- Данные партнёра — только из сессии (T-006).
**Вне скоупа:** песочница и мок APIgw (T-008, T-009), универсальные формы (T-003).
**Зависит от:** T-004, T-006, T-008, T-010
