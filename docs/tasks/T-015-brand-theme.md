# T-015: Тема UI в корпоративном стиле МТС

**Цель:** NFR-8 — единая тема, на которой строятся все страницы. Источник значений — `docs/ui/brand.md` (референс mws.ru; не усложнять).
**Файлы:** `app/static/theme.css`, `app/templates/base.html` (шапка, подключение темы), `app/static/brand/` (официальный SVG логотипа — после решения пользователя), `.gitignore` (`app/static/fonts/`), тест-страница `/_ui` (кнопки, поля, таблица, плашки, баннер приоритета).
**Критерии приёмки:**
- Токены бренда, нейтральные, статусы и радиусы из `brand.md` определены только в `theme.css`; остальные шаблоны используют переменные и классы (`.btn`, `.card`, `.badge-*`, `.stat`, `.table`), а не цвета.
- Шрифты: `MTS Wide` для заголовков/кнопок, `MTS Text`/`MTS Compact` для текста, замена на Arial; без файлов шрифтов страница выглядит корректно.
- Шапка по образцу mws.ru: белая, логотип слева (до решения о файле — текст «МТС»), название продукта текстом рядом, справа меню и «Выйти»; подвал тёмный.
- Компоненты: основная кнопка (красная), вторичная, недоступная; поля, таблица, плашки ошибок/успеха, баннер приоритета `⚡`.
- Страница `/_ui` показывает все компоненты; контраст текста достаточен.
**Вне скоупа:** содержимое экранов (T-003, T-014 и др.).
**Зависит от:** T-000
