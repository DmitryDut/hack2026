# Глоссарий

| Термин | Значение |
|---|---|
| **PX** (Partner eXperience) | Витрина и процессы работы с партнёром: регистрация, контракт, оффер, цена, счёт. Внешняя для нас система |
| **PRM** | Partner Relationship Management, часть PX/витрины |
| **QP** (QoS Platform) | QoS-платформа оператора |
| **QoD** (Quality on Demand) | CAMARA API: запрос качества сети по требованию для устройства и сервера |
| **QoD management** | Наша часть: инвентори сервисов партнёра, процессы конфигурирования и запуска |
| **CAMARA** | Проект Linux Foundation: открытые API операторов |
| **GSMA Open Gateway / APIgw** | Шлюз API операторов по стандартам GSMA, точка входа в ядро сети |
| **SCEF / NEF** | Узлы экспозиции возможностей сети (4G / 5G); интерфейс T8, TS 29.122 |
| **PCRF / PCEF** | Политики и их применение в 4G; сюда «вносится» конфигурация при запуске |
| **AF** | Application Function, приложение, которое просит сеть о QoS |
| **Dedicated Bearer (DB)** | Выделенный канал в 4G с гарантированным качеством для трафика |
| **IPTOMS** | Система, по UUID возвращающая MSISDN/IP/IMSI абонента |
| **Сигнатура** | Описание трафика сервиса: `{IPv4, URI, port, protocol}` |
| **QoS-профиль** | Набор параметров качества (уровень, полоса, задержка, max duration, SLA); ≈5 уровней (QOS_S/M/L/E) |
| **Duration** | Срок действия QoS для сервиса/сессии |
| **Песочница** | Эмулированный тестовый прогон сервисов партнёра перед коммерческим запуском |
| **Partner_ID / client_id** | Условный идентификатор партнёра из PX (в диаграмме `partners-1`) |
| **CJ** (Customer Journey) | Оркестратор HTML-форм и вызовов на диаграмме задания |
| **RC** (Resource Catalog) | Каталог ресурсов, в том числе QoS-профилей |
| **MSISDN** | Телефонный номер абонента |
| **Инвентори** | Ресурсно-сервисный реестр: партнёры, сервисы, сигнатуры, профили |
| **CDR / EDR** | Первичные записи об использовании для биллинга (вне скоупа) |
