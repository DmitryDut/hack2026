## Что это за проект
Прототип для хакатона МТС: QoS-платформа (QoD management). Партнёр сам конфигурирует сервисы (сигнатуры, QoS-профиль, срок), видит цену, проходит песочницу, запускает приоритет; затем сервис подключается абоненту. **Главный критерий оценки:** после демо организаторы просят «поменяйте вот это» и замеряют время — модель, процесс, цена и UI должны меняться конфигом без правки кода.
