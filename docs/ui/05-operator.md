# Кабинет оператора — `/operator`

Требования: SBX-6, SBX-8, SBX-9, TRC-1, NFR-3. Сценарии: S-08, N-07…N-08.
Назначение: оператор МТС видит партнёров, их конфигурации, всё, что происходило, и все «внешние» вызовы. Вход в демо — без пароля.

## 5.1 Партнёры
```text
Оператор │ Партнёры │ Журнал событий │ Внешние вызовы │ Абоненты

Партнёры
┌──────────────┬──────────────┬─────────┬────────────┬──────────────────────┐
│ ID           │ Название     │ Сервисов│ Запущено   │                      │
├──────────────┼──────────────┼─────────┼────────────┼──────────────────────┤
│ mts-link-1   │ MTS Link     │ 2       │ 1 из 2     │ [Открыть]            │
│ other-partner│ Другой       │ 0       │ 0          │ [Открыть]            │
│ partners-1   │ Компания Х   │ 0       │ 0          │ [Открыть]            │
└──────────────┴──────────────┴─────────┴────────────┴──────────────────────┘
```
`partners-N` — партнёры, созданные через флоу диаграммы (`06-landing-flow.md`).

## 5.2 Карточка партнёра
```text
MTS Link (mts-link-1)                                  статус: active
┌ Сервисы ─────────────────────────────────────────────────────────────────┐
│ Link ВКС   Платина · 12 ч    30 000 ₽/мес   ⚡ Приоритет активен  qod-session-8f3a2b │
│            [Журнал сервиса]  [Сбросить в черновик (оператор)]            │
│ Link Чаты  Золото · 24 ч      17 000 ₽/мес   ○ Черновик                     │
│            [Журнал сервиса]                                              │
└──────────────────────────────────────────────────────────────────────────┘
[Экспорт JSON для PX]
```
- `[Сбросить в черновик (оператор)]` — только для сервисов в статусе «Приоритет активен»; диалог: «Сбросить сервис в черновик? Действие попадёт в журнал» `[Сбросить] [Отмена]` → `POST …/sandbox/operator-reset {confirm:true}`; событие `applied_reset`.
- `[Экспорт JSON для PX]` показывает ответ `GET /api/v1/partners/{id}/export` (только подтверждённые сервисы).

## 5.3 Журнал событий
```text
Журнал событий                  Партнёр [Все ▼]  Сервис [Все ▼]  Событие [Все ▼]
┌──────────┬───────────┬───────────────┬─────────────────────────────────┐
│ Время    │ Сервис    │ Событие       │ Детали                          │
├──────────┼───────────┼───────────────┼─────────────────────────────────┤
│ 12:05:10 │ svc-vcs   │ run_started   │ шагов 4: draft → in_testing     │
│ 12:05:40 │ svc-vcs   │ run_failed    │ step_error: in_testing → failed │
│ 12:09:02 │ svc-vcs   │ change_rejected│ applied_locked (попытка правки)│
│ …        │           │               │                                 │
└──────────┴───────────┴───────────────┴─────────────────────────────────┘
```
Порядок — по времени по возрастанию (по умолчанию новые внизу; переключатель `[Новые сверху]`). Клик по строке разворачивает `details` (JSON). Источник — таблица `event_log`.

## 5.4 Внешние вызовы
```text
Внешние вызовы (моки)           Тип [Все ▼]   Партнёр [Все ▼]
┌──────────┬──────────────────┬────────────────────────────┬────────┐
│ Время    │ Тип              │ Метод и путь               │ Код    │
├──────────┼──────────────────┼────────────────────────────┼────────┤
│ 12:05:14 │ gsma_validate    │ POST /mock-gsma/validate   │ 200    │
│ 12:07:01 │ gsma_session     │ POST /mock-gsma/qod/sessions│ 201   │
│ 12:08:14 │ qos_assignment_create │ POST /mock-gsma/qos-assignments │ 201 │
└──────────┴──────────────────┴────────────────────────────┴────────┘
 ▾ Запрос                              ▾ Ответ
 { "partner_id": "mts-link-1", … }     { "session_id": "qod-session-8f3a2b", … }
```
Клик по строке раскрывает запрос и ответ (JSON). Для `gsma_validate` с `result: error` строка выделяется `⚠` (код всё равно 200). Источник — `network_request`.

## 5.5 Абоненты
Ссылка на универсальный список `/entities/subscriber` и карточки `/subscribers/{msisdn}`; оператор видит все сервисы абонента от всех партнёров.

## Что проверить при ревью
1. Нужен ли оператору «одобряющий» экран (онбординг уже пройден в PX — по требованиям нет).
2. Нужен ли оператору просмотр трассировки (сейчас в витрине).
3. Фильтры журналов и сворачиваемые JSON — достаточно ли.
4. Должен ли оператор сам запускать сервис (сейчас — только партнёр; оператор лишь сбрасывает).
