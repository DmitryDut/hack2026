# Витрина PX (мок)

Требования: EMB-1…EMB-5, MOCK-3, TRC-2, NFR-4. Сценарии: S-01, S-04, N-01…N-03.

## 1.1 Страница партнёра в витрине — `/px-showcase`
Назначение: изображает личный кабинет партнёра в PX, откуда запускается личный кабинет с конфигуратором услуг. Кто видит: партнёр (в демо — жюри). Тот же кабинет доступен напрямую после входа (`00-login.md`).

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ Партнёр eXperience (мок)                         Партнёр: MTS Link ▾    │
├──────────────────────────────────────────────────────────────────────────┤
│  Предложение «Приоритет для вашего трафика»                              │
│  Гарантируйте качество видеосвязи и чатов даже при перегрузке сети.      │
│                                                                          │
│  [Конфигурировать сервисы QoS]     Открыть в новой вкладке ↗             │
│                                                                          │
│ ┌ iframe: /embed?token=… ──────────────────────────────────────────────┐ │
│ │ QoD management │ Партнёр: MTS Link (mts-link-1) — из токена          │ │
│ │ (личный кабинет партнёра, см. 02-cabinet.md; без формы входа — сквозная авторизация)                   │ │
│ └──────────────────────────────────────────────────────────────────────┘ │
│                                                                          │
│ ▸ Трассировка сообщений                                                  │
└──────────────────────────────────────────────────────────────────────────┘
```
- Iframe появляется после нажатия кнопки (до этого — только карточка предложения).
- Токен генерирует сервер на странице (`partner_id`, срок 1 час); пользователь его не видит и не вводит.
- «Открыть в новой вкладке» открывает тот же `/embed?token=…`.
- Переключатель партнёра (`MTS Link` / `Другой партнёр`) нужен для демонстрации изоляции (SBX-9).

Действия:
| Действие | Результат | API |
|---|---|---|
| `[Конфигурировать сервисы QoS]` | открывается iframe | `GET /embed?token=…` |
| `[Открыть в новой вкладке]` | кабинет в отдельной вкладке (callback-режим: итог на его странице) | то же |
| получено `postMessage(qod:export)` | показывается карточка 1.2 | — |

## 1.2 Карточка «Партнёр подключён»
Появляется под iframe после нажатия «Отправить в витрину PX» в кабинете (`02-cabinet.md`, 2.5).

```text
┌─ ✓ Партнёр подключён   ⚡ Приоритет включён: 1 из 2 услуг ────────────────┐
│ Партнёр: MTS Link (mts-link-1)          Предложение: Базовый (подтверждено)│
├───────────────┬───────────┬────────┬──────────────────────┬──────────────┤
│ Сервис        │ Профиль   │ Срок   │ SLA                  │ Цена         │
├───────────────┼───────────┼────────┼──────────────────────┼──────────────┤
│ Link ВКС      │ Платина   │ 12 ч   │ 99.95 %              │ 30 000 ₽/мес │
│ Link Чаты     │ Золото    │ 24 ч   │ 99.9 %               │ 10 000 ₽/мес │
├───────────────┴───────────┴────────┴──────────────────────┼──────────────┤
│                                                      Итого │ 40 000 ₽/мес │
└────────────────────────────────────────────────────────────┴──────────────┘
  [Показать JSON]
```
- Данные — из ответа `qod:export` (формат `docs/px-json-proposal.md`) и цен мока PX (`POST /px/price`).
- Признак `⚡ Приоритет включён` строится по статусам услуг партнёра (`applied`); если ни одной нет — «○ Приоритет ещё не включён».
- `[Показать JSON]` раскрывает полученный JSON (читаемый, с подсветкой).
- Строка в варианте V5-эталона (`Gold`, SLA 99.9 %, 10 000) — частный случай одного сервиса.

## 1.3 Панель «Трассировка сообщений»
```text
▾ Трассировка сообщений                                     проход: a1b2c3
 №  │ От → Кому                              │ Сообщение                       │ Время
 1  │ Service Provider → Partner Landing     │ GET /qos_platform/landing       │ 12:00:01.120
 2  │ Partner Landing → Customer Journey     │ GET /cj/qos_platform (empty)    │ 12:00:01.125
 …  │ …                                      │ …                               │ …
 17 │ Customer Journey → Partner Landing     │ content: «Партнёр подключён» …  │ 12:00:04.870
 Покрыто реплик: 17 из 17 ✓
```
Показывает последний проход флоу (см. `06-landing-flow.md`). Если реплик меньше 17 — строка `Покрыто реплик: 9 из 17 ⚠` и недостающие номера серым.

## 1.4 Страница ошибки токена — `/embed?token=…` (плохой токен)
```text
┌──────────────────────────────────────────┐
│ ⚠ Токен недействителен                   │
│ Откройте кабинет из витрины заново. │
│ Причина: подпись не сошлась              │
└──────────────────────────────────────────┘
```
Причины (разные тексты): «подпись не сошлась», «срок действия истёк», «неверный формат». Данные партнёра и кабинет не загружаются. Отдельной кнопки «повторить» нет.

## 1.5 Страница предложения `/mock-px?partner_id=…`
Вид карточки 1.2 на отдельной странице без iframe (для сверки с V1 F9, A6). Если подтверждённых сервисов нет: `У партнёра нет подтверждённых сервисов` и пустая таблица.

## Что проверить при ревью
1. Достаточна ли витрина с одной кнопкой — нужны ли в ней дополнительные элементы «как в PX» (продукты, тарифы).
2. Нужна ли в карточке строка с итогом и список всех сервисов (V5 показывает один).
3. Нужен ли переключатель партнёра в витрине (используется только для показа изоляции).
4. Формулировки: «Партнёр подключён», «Конфигурировать сервисы QoS».
