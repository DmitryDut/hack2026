# Драфты интерфейсов (v2)

**Статус: черновик для ревью, вторая редакция.** Макеты — ASCII-схемы: состав экрана, поля, кнопки, состояния и тексты, а не дизайн. Источник требований — `docs/requirements.md`, техника — `docs/SPEC.md` (§6–§10), сценарии — `docs/scenarios.md`.
Тексты, названия кнопок и порядок элементов — **мои допущения**; в конце каждого файла раздел «Что проверить при ревью».

## Образ результата (что должен увидеть пользователь)
1. **Страница авторизации партнёра** — `00-login.md`.
2. **Личный кабинет**, где партнёр добавляет услуги и указывает IP, порты, протоколы и остальные данные для настройки QoS — `02-cabinet.md` (2.1–2.3).
3. **Расчёт стоимости** по тарифам из задания (Бронза 10, Серебро 30, Золото 50, Платина 100, Бриллиант 200 Мбит/с; цена = Мбит/с × 100 ₽ × коэффициент) — `02-cabinet.md` (2.4, 2.5).
4. **Признак «трафик приоритизирован»** после включения приоритета — баннер и строка услуги в кабинете, панель в карточке услуги, карточка абонента, карточка в витрине PX (`02-cabinet.md` 2.1 и 2.7, `03-subscriber.md`, `01-px-showcase.md`).

## Условные обозначения
| Знак | Значение |
|---|---|
| `[Кнопка]` | кнопка; `[Кнопка ▒]` — недоступна (серая) |
| `(•) / ( )` | радио выбран / не выбран |
| `[x] / [ ]` | чекбокс |
| `[Выбор ▼]` | выпадающий список |
| `________` | текстовое поле; `*` — обязательное |
| `{{ ... }}` | значение из системы |
| `✓` `✗` `⚠` `…` | успех, ошибка, предупреждение, ожидание |
| `⚡` | **трафик приоритизирован** (приоритет включён в сети) |
| `○ ◐ ⏱` | черновик, идёт тест, срок приоритета истёк |
| `┌─┐` | рамка блока, карточки или модального окна |

## Роли и вход
| Роль | Как попадает | Что видит |
|---|---|---|
| Партнёр | форма `/login` или вход из витрины `/embed?token=…` | свои услуги, тарифы, абонентов |
| Оператор | кнопка «Войти как оператор» на `/login` или прямо `/operator` | всех партнёров, журналы, сброс |
| Админ схем | `/admin/schemas` (в демо без входа) | схемы и справочники |

Сессия — подписанный токен (`partner_id`, срок); идентификатор из неё подставляется как `X-Partner-Id` во все запросы кабинета, чужие данные — 404.

## Общие элементы
**Шапка сайта** (вне фрейма): `Платформа качества связи`; в кабинете меню: `Услуги │ Стоимость и предложение │ Абоненты │ Журнал │ Выйти`.
**Режим встраивания** `?embed=1`: шапка сайта скрыта, меню кабинета остаётся.
**Статусы услуги:** `○ Черновик`, `◐ Тест идёт`, `✗ Тест не пройден`, `✓ Тест пройден`, `⚡ Приоритет активен до {{время}}`, `⏱ Срок приоритета истёк`.
**Сообщения об ошибках:** 422 — под полем (`⚠ Порт должен быть от 1 до 65535`); 409 — плашка над формой; 404/токен — отдельная страница ошибки.
**Пустые состояния:** текст и действие («Услуг пока нет. [+ Добавить услугу]»).
**Панели наблюдаемости:** «Журнал событий», «Внешние вызовы» (у партнёра — только его), «Трассировка» (в витрине).
**Тексты UI** — русские; цены `30 000 ₽/мес`; срок `12 ч`; скорость `100 Мбит/с`; тарифы — Бронза, Серебро, Золото, Платина, Бриллиант.

## Что проверить при ревью (общее)
1. Достаточно ли «входа по логину и паролю-заглушке» и роли оператора кнопкой.
2. Нужна ли шапка сайта в режиме без iframe.
3. Язык и формулировки — в каждом файле отдельно.
4. Соответствие образу результата: пункты 1–4 выше.
