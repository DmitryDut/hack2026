**Статус: черновик для ревью.** Макеты — ASCII-схемы: показывают состав экрана, поля, кнопки, состояния и тексты, а не дизайн. Источник требований — `docs/requirements.md`, техника — `docs/SPEC.md` (§6–§10). Сценарии — `docs/scenarios.md`.
Тексты, названия кнопок и порядок элементов — **мои допущения**; в конце каждого файла раздел «Что проверить при ревью».

## Карта переходов
```text
                       ┌────────────────────────────────────────────┐
  /  ───────────────►  │ /px-showcase (витрина, партнёр mts-link-1) │
  │                    └──────┬───────────────────────┬─────────────┘
  │                           │ iframe + токен        │ postMessage(qod:export)
  │                           ▼                       ▼
  │                    /embed → /configurator/*   карточка «Партнёр подключён»
  │                      1 сервисы → 2 профиль → 3 предложение → 4 песочница → 5 запуск
  │                                                                    │
  │                                                                    ▼
  ├──► /operator  (журналы, партнёры)                        /subscribers/{msisdn}
  ├──► /admin/schemas ─► /entities/{type}  (модель и справочники)
  └──► /qos_platform/landing → регистрация → выбор профиля → «Партнёр подключён»  (флоу из задания)
```

## Условные обозначения
| Знак | Значение |
|---|---|
| `[Кнопка]` | кнопка; `[Кнопка ▒]` — недоступна (серая) |
| `(•) / ( )` | радио выбран / не выбран |
| `[x] / [ ]` | чекбокс |
| `[Выбор ▼]` | выпадающий список |
| `________` | текстовое поле; `*` — обязательное |
| `{{ ... }}` | значение из системы |
| `✓` `✗` `⚠` `…` | успех, ошибка, предупреждение, ожидание |
| `┌─┐` | рамка блока, карточки или модального окна |

## Роли и вход
| Роль | Как попадает | Что видит |
|---|---|---|
| Партнёр | через витрину: `/embed?token=…`; в режиме разработки — `?partner_id=mts-link-1` | свои сервисы, предложения, песочницу, абонентов |
| Оператор | `/operator` (в демо без входа) | всех партнёров, журналы, operator-reset |
| Админ схем | `/admin/schemas` (в демо без входа) | схемы и справочники |
API партнёра — заголовок `X-Partner-Id`; чужой партнёр = 404.

## Общие элементы
**Шапка сайта** (вне фрейма): `Платформа качества связи │ Витрина │ Оператор │ Схемы`.
**Шапка embed** (в iframe/вкладке): `QoD management │ Партнёр: {{partner_name}} ({{partner_id}}) — из токена`; меню сайта скрыто.
**Степпер шагов** — из `config/process.yaml`; шаг недоступен, если не выполнено условие (`gates`), с подсказкой «почему».
**Сообщения об ошибках:**
- 422 — под полем, красным: `⚠ Порт должен быть от 1 до 65535`;
- 409 — плашка над формой: `⚠ Такая сигнатура уже есть у сервиса`;
- 404/токен — отдельная страница ошибки (без данных партнёра).
**Пустые состояния:** текст и действие (`Сервисов пока нет. [Добавить сервис]`).
**Панели наблюдаемости** (раскрываются внизу экрана): «Журнал событий» (из `event_log`), «Внешние вызовы» (из `network_request`), «Трассировка» (из `trace_entry`).
**Тексты UI** — русские; цены `30 000 ₽/мес`; срок `12 ч`; скорость `100 Мбит/с`.

## Что проверить при ревью (общее)
1. Достаточно ли трёх ролей и «входа без пароля» для демо.
2. Нужна ли шапка сайта с меню в режиме без iframe.
3. Язык и формулировки (ниже в файлах — по каждому экрану).
