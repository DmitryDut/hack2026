# Абонент

Требования: SUB-1…SUB-3, STD-3. Сценарии: S-07, N-09, N-10.

## 3.1 Подключение сервиса абоненту
Расположено на вкладке «④ Запуск и абоненты» карточки услуги (`02-cabinet.md`, 2.7) и доступно только для услуги с активным приоритетом (`applied`).

```text
Подключить сервис «Link ВКС» абоненту
Номер абонента*   [+7 916 123 00 01]
                  [Подключить]
```
Результат (под формой, через HTMX):
```text
✓ Подключено: +7 916 123 00 01 · Link ВКС · Платина
  ⚡ Трафик приоритизирован
  Статус назначения: REQUESTED → AVAILABLE      assignmentId: asg-7f21
  [Открыть карточку абонента]
```
Ошибки:
| Случай | Текст | Код |
|---|---|---|
| сервис не `applied` | «Сначала включите приоритет для услуги» | 409 |
| номер не в формате `+7XXXXXXXXXX` | «Неверный формат номера» | 422 |
| номера нет в базе абонентов | «Абонент не найден» | 404 |
| уже подключён | «Этот сервис уже подключён абоненту» | 409 |
Под капотом: `POST /mock-gsma/qos-assignments {device:{phoneNumber}, qosProfile}` → `REQUESTED`, затем `GET …/{id}` → `AVAILABLE`; оба вызова в «Внешних вызовах».

## 3.2 Карточка абонента — `/subscribers/{msisdn}`
```text
Абонент +7 916 123 00 01        Тариф связи: Smart      Регион: Москва
┌──────────────────────────────────────────────────────────────────────┐
│ ⚡ Трафик приоритизирован: Link ВКС · Платина (до 100 Мбит/с)         │
└──────────────────────────────────────────────────────────────────────┘

Подключённые сервисы
┌──────────────┬────────────┬──────────┬────────┬────────────┬────────────┐
│ Сервис       │ Партнёр    │ Тариф    │ Срок   │ Статус     │ Приоритет  │
├──────────────┼────────────┼──────────┼────────┼────────────┼────────────┤
│ Link ВКС     │ MTS Link   │ Платина  │ 12 ч   │ AVAILABLE  │ ⚡ до 00:07 │
└──────────────┴────────────┴──────────┴────────┴────────────┴────────────┘

Таймлайн
 12:08:14  assignment_requested   Link ВКС → +7 916 123 00 01
 12:08:15  assignment_available   Link ВКС
```
- Партнёр видит только свои сервисы абонента (чужие скрыты; изоляция по `X-Partner-Id`).
- Оператор (в `/operator`) видит все.
- Верхняя плашка `⚡ Трафик приоритизирован` — если есть назначение `AVAILABLE` и срок приоритета услуги не истёк; при `REQUESTED` — `… Включается`; при истёкшем сроке — `⏱ Срок приоритета истёк`; иначе плашки нет.
- Пусто: «У абонента нет подключённых сервисов».
- Поиск по номеру — поле над карточкой; ненайденный номер: «Абонент не найден».

## 3.3 Список абонентов (вспомогательный)
Страница `/entities/subscriber` (универсальный список): номер, тариф, регион, кнопка «Открыть» → 3.2. Нужна, чтобы выбрать номер для демо.

## Что проверить при ревью
1. Подключение абоненту — на шаге запуска; нужен ли отдельный экран «Абоненты» в меню.
2. Состав карточки: нужен ли показ срока окончания и session_id.
3. Допустимо ли, что подключение мгновенно доходит до `AVAILABLE` (мок), без ожидания.
4. Нужны ли массовое подключение (список номеров) и отключение (`DELETE /qos-assignments`) — сейчас нет.
