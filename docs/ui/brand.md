# Корпоративный стиль МТС для UI

**Статус: первая редакция по открытым материалам.** Источник — страница https://moskva.mts.ru/about/media-centr/mediabank/korporativnyj-stil (проверена 2026-11-03) и файлы, на которые она ссылается. Файлы скачаны во временную папку **вне репозитория** и разобраны; в git не добавлялись.
Требование: UI итогового демо — в корпоративном стиле МТС 2026 (NFR-8).

## Чего в источниках нет (и что я принимаю сам)
- **Нет палитры, кроме красного:** фоны, серые тона, цвета статусов (успех, ошибка, предупреждение) в прочитанных материалах не заданы. В макетах и теме использую **нейтральные рабочие значения** (ниже) и помечаю их «не из брендбука».
- **Нет упоминания «стиля 2026».** Файлы без даты; метаданных PDF нет. Является ли это «МТС 2026» — не подтверждено. Если у организаторов есть актуальный гайдлайн, UI-кит или макеты — они приоритетнее этого документа.
- **Нет правил для интерфейсов:** кнопки, поля, таблицы, отступы в логобуке и типографике не описаны (это гид по логотипу и шрифтам).
- Шрифты МТС (MTS Wide, MTS Text, MTS Compact) — файлы лежат в отдельном архиве (`mts_shrift.7z`); я его не скачивал. Условия использования шрифта в вебе не проверены.
- Не прочитаны: «Логотипы экосистемы» (PDF), архив `mts_logo_new.zip`.

## Решения для UI (предложение, к ревью)
### Токены темы (`app/static/theme.css`, CSS-переменные поверх Pico.css)
| Токен | Значение | Источник |
|---|---|---|
| `--mts-red` | `#FF0032` | бренд |
| `--mts-white` | `#FFFFFF` | бренд |
| `--mts-black` | `#000000` | допущение (чёрно-белый вариант логотипа допустим) |
| `--text` | `#1D2023` | **допущение, не из брендбука** |
| `--text-muted` | `#626C77` | допущение |
| `--bg` | `#FFFFFF`; `--bg-subtle` `#F2F3F7` | допущение |
| `--border` | `#E2E5EB` | допущение |
| `--success` | `#27AE60` | допущение |
| `--warning` | `#F5A623` | допущение |
| `--error` | `#C8102E` | допущение: тёмнее фирменного красного, чтобы ошибки не сливались с брендовыми акцентами |
Признак приоритета (⚡) — значок на белой карточке с красным акцентом; решается при реализации.

### Шрифты
`font-family: "MTS Wide", "MTS Compact", Arial, sans-serif` для заголовков и кнопок; `"MTS Text", "MTS Compact", Arial, sans-serif` для основного текста. Если файлов шрифта в проекте нет — работает **Arial** (по правилу типографики). Файлы шрифта в репозиторий не добавляем без явного разрешения (лицензия); подключаются локально через `@font-face`, если пользователь положит их в `app/static/fonts/` (папка в `.gitignore`).

### Логотип в шапке
- Используем **официальный SVG** (`MTC_Logo_RGB.svg`, 1.8 КБ), без перерисовки и изменений; в шапке — вариант без надписи «цифровая экосистема» (размер меньше 16 мм).
- Охранное поле ½ «М» вокруг; слева в шапке; рядом нет добавок вроде «QoD» внутри логотипа — название продукта выносится отдельным текстом справа от логотипа.
- Вопрос включения SVG в репозиторий — на ваше решение (публичный репозиторий).

### Компоненты (общие правила для макетов)
Кнопка основная — красный фон, белый текст; вторичная — белая с чёрной обводкой; недоступная — серая. Карточки — белые с тонкой границей, острые или слегка скруглённые углы. Таблицы — светлые заголовки, строки без зебры. Баннер приоритета — белая карточка с красным акцентом слева и значком ⚡.

## Что проверить при ревью
1. Принимаете ли нейтральные цвета как рабочие (в брендбуке их нет)? Есть ли у организаторов актуальный UI-кит или палитра 2026?
2. Можно ли положить официальный SVG-логотип в публичный репозиторий.
3. Есть ли доступ к шрифтам МТС для демо или идём на Arial.
4. Нужны ли логотип партнёра/кобрендинг (в логобуке есть раздел) — сейчас нет.
