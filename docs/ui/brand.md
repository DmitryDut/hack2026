# Корпоративный стиль МТС для UI

**Статус: v3, логотип и шрифты подключены (разрешено пользователем); референс — https://mws.ru** (MTS Web Services, проверен 2026-11-03). Значения взяты из CSS самого сайта (публичная страница) и сверены с логобуком и типографикой МТС. Принцип — **не усложнять**: светлая тема, красный акцент, нейтральные серые, три шрифта, скругления 8 px. Файлы шрифтов и логотипа в git не добавляем.
Требование: NFR-8 (UI в корпоративном стиле МТС 2026). Сайт mws.ru датирован © 2026 — это лучший доступный образец актуального стиля; официального подтверждения «стиль 2026» нет.

## Шрифты
Сайт использует **MTS Wide** (заголовки, кнопки), **MTS Text** (основной текст), **MTS Compact** (мелкий текст), начертания Regular/Medium/Bold, файлы woff2. Это совпадает с типографикой МТС (Wide Medium — основной, Text/Compact — наборные, Arial — запасной).
```css
--font-head: "MTS Wide", "MTS Compact", Arial, sans-serif;
--font-text: "MTS Text", "MTS Compact", Arial, sans-serif;
```
- Файлы woff2 лежат в `app/static/fonts/` и подключены через `@font-face` в `theme.css` (Wide Medium/Bold, Text Regular/Medium, Compact Regular/Medium); запасной шрифт — **Arial**.
- Условия использования шрифтов МТС вне собственных сайтов не проверены — вопрос к пользователю.

## Логотип
- Использовать **официальный SVG** (`MTC_Logo_RGB.svg` из архива логотипов МТС), без перерисовки, обводок, эффектов и изменения пропорций; типографика внутри логотипа всегда белая.
- Охранное поле — ½ высоты модуля «М»; в шапке — вариант без надписи «цифровая экосистема» (малый размер).
- Название продукта («QoD management» / «Личный кабинет») — отдельным текстом рядом, **не внутри логотипа**.
- Официальный SVG лежит в `app/static/brand/mts-logo.svg`, показан в шапке 36×36 px без надписи «цифровая экосистема».

## Облик интерфейса (по mws.ru, упрощённо)
- **Шапка:** белая, слева логотип и название продукта; справа ссылки меню и кнопка «Выйти»; внизу тонкая граница. Без мега-меню.
- **Главная кабинета:** заголовок страницы (MTS Wide Medium), баннер приоритета и ряд карточек-показателей на `#F2F3F7` (как блоки «Опыт / Сервис / Надёжность» на сайте) — «Услуг», «Приоритет включён», «Стоимость в месяц».
- **Карточки и таблицы:** белые, граница `#E2E5EB`, радиус 12 px; заголовки таблиц на `#F9F9FB`; без зебры.
- **Кнопки:** основная — фон `#FF0032`, белый текст, радиус 8 px; вторичная — белая с чёрной границей или «ghost»; недоступная — серая `#E2E5EB`/текст `#969FA8`.
- **Признак приоритета ⚡:** зелёная плашка (`success`) с текстом «Трафик приоритизирован»; «⏱ срок истёк» — жёлтая плашка.
- **Подвал:** тёмный `#0D1012`, белый текст, юридическая строка «© 2026 …».
- Тема — только светлая.

## Реализация
Один файл `app/static/theme.css` с переменными выше поверх Pico.css (переопределение `--pico-primary` и т. п.) и класс-«компоненты»: `.btn`, `.btn-secondary`, `.card`, `.badge-success|warning|error|info`, `.stat`, `.table`. Остальные шаблоны используют только переменные и классы (задача T-015, `docs/tasks/T-015-brand-theme.md`).

## Что проверить при ревью
1. Достаточно ли «в духе mws.ru» (светлая тема, красный акцент, карточки) или нужен другой образец.
2. Можно ли положить официальный SVG-логотип в публичный репозиторий.
3. Есть ли у вас шрифты МТС для демо (они общедоступны на mws.ru, но лицензию я не проверял); иначе Arial.
4. Цвет ошибок: оранжево-красный из шкалы сайта (`#FD502E`), а не брендовый красный.
