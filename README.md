# Платформа управления качеством мобильной связи — POC (хакатон 2026)

Реализуем: **онбординг партнёра** и **часть схем подключения**. Демо: партнёр проходит онбординг →
оператор одобряет → партнёр выбирает схему подключения → подключает услугу конкретному абоненту (MSISDN).

## Запуск
```bash
uv sync
make reset   # создать БД с демо-данными
make dev     # http://localhost:8000 , Swagger: /docs
make check   # линтер + тесты
```
